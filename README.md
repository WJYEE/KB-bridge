# 내집내산 (첫집ON) — My First Home Navigator

> 집을 찾아주는 서비스를 넘어, 첫 집을 결정할 수 있게.

청년이 첫 주택 구매 시 자신의 예산과 선호조건에 따라 어떤 선택을 해야 하는지,
2024~2026년 서울시 실거래 데이터로 판단하도록 돕는 주거·금융 의사결정 웹서비스입니다.

이 서비스는 "어떤 집이 좋은지 알려주는 서비스"가 아니라, **내 자산과 선호를
고려했을 때 무엇을 선택하고 무엇을 포기해야 하는지를 실거래 데이터로 설명하는
서비스**입니다.

## 핵심 기능

- **Assessment** (`/assessment`) — 예산·희망지역·면적·연식·주택유형·중요도를
  4단계로 입력
- **Result** (`/result`) — 실거래 데이터 기반 추천 지역 TOP 5, 각 추천의 점수·근거·Trade-off,
  최대 3개 지역 비교
- **Trade-off Simulator** (`/tradeoff`) — 조건 하나를 바꿨을 때 선택 가능한 거래·지역·면적·가격이
  실제로 어떻게 달라지는지 계산
- **금융 시뮬레이션** (`/finance`) — 원리금균등상환 기준 월 상환액·총 이자 계산,
  BUY/WAIT/RENT&GROW 개념 미리보기

## 실행 방법

```bash
npm install
npm run preprocess   # data/raw/최종1차데이터셋.xlsx → data/processed/*.json 생성 (최초 1회, 또는 원본 데이터 변경 시)
npm run dev           # http://localhost:3000
```

테스트:

```bash
npm test              # vitest — 추천 엔진/Trade-off/금융 계산 단위 테스트
```

빌드:

```bash
npm run build
npm start
```

## 데이터 출처

- `data/raw/최종1차데이터셋.xlsx` (Sheet2) — 2024~2026년 서울시 부동산 실거래가
  정보를 취소거래·핵심 결측치 기준으로 정제한 최종 데이터셋 (284,102건)
- `data/raw/[종합실습] 서울시 부동산 실거래가 정보_2024/2025/2026.csv` — 연도별 원본
  (계보 보존용, 서비스 로직에서는 직접 사용하지 않음)
- `data/raw/2026 KB부동산보고서.pdf` — 시장 Insight 참고 자료 (P1 예정)

## 데이터 전처리

```bash
npm run preprocess
```

`scripts/preprocess-realestate.ts`가 원본 xlsx를 읽어 핵심 컬럼 결측/가격·면적
유효성을 재검증하고, 파생변수 계산에 필요한 형태로 `data/processed/*.json`
(모두 재생성 가능, git에는 커밋하지 않음)을 생성합니다. 상세 내용은
[DATA_ANALYSIS.md](DATA_ANALYSIS.md) 참고.

## 추천 알고리즘 개요

`src/lib/recommendation/`이 추천 엔진입니다.

1. 자치구별로 사용자 조건(예산/면적/연식/지역/유형/층)을 실거래 데이터에 필터링
2. 가격·공간·신축·지역·주택유형·층·시장안정성·거래활성도 8개 점수(0~100)를 각각 계산
   (`score.ts`)
3. 사용자가 입력한 중요도 가중치로 정규화 후 가중합 (`recommend.ts`)
4. 점수 근거를 실제 통계 수치로 설명하는 문장 생성 (`explain.ts`) — 임의 문구 없음
5. `tradeoff.ts`의 `simulateTradeoff()`로 조건 변경 시뮬레이션

추천 알고리즘의 상세 근거(정규화 방식, 최소표본 기준, 안정성/유동성 정의 등)는
[DECISION_LOG.md](DECISION_LOG.md)에 기록되어 있습니다.

## 사용한 파생변수

| 변수 | 정의 |
|---|---|
| 평수 | `건물면적(㎡) / 3.3058` |
| ㎡당가격 | `물건금액(만원) / 건물면적(㎡)` |
| 평당가격 | `물건금액(만원) / 평수` |
| 건물연식 | `계약연도 - 건축년도` |
| 면적/가격/연식/층 구간 | `src/lib/realestate/derive.ts` (경계값 근거 주석 포함) |
